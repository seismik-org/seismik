SEISMIK API

Términos de uso de la beta

Versión: 2026-08-30

Uso permitido

La API gratuita se ofrece para investigación, educación y prototipos responsables. Debes conservar la atribución de la fuente oficial y respetar las cuotas.

Limitaciones

Los datos pueden ser preliminares, incompletos o revisados. No debes presentar Seismik como sustituto de una autoridad, un sistema certificado de alerta ni usar esta beta como única señal para controlar equipos críticos.

Seguridad y privacidad

No compartas claves ni intentes eludir cuotas. Seismik registra metadatos mínimos de autenticación y consumo para proteger el servicio; no vende datos personales.

Disponibilidad

La beta se ofrece sin garantía de continuidad. Podemos revocar credenciales abusivas o modificar límites con aviso razonable.

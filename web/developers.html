Clave de API gratuita

Plan Free Una cuenta Google/Firebase verificada puede crear una clave personal. Se muestra una sola vez, se almacena únicamente como hash y puede revocarse.

Flujo: iniciar sesión, solicitar POST /v1/developer/keys con el token Firebase y guardar la clave.

curl -H "Authorization: Bearer FIREBASE_ID_TOKEN" -X POST https://api.seismik.org/v1/developer/keys
curl -H "X-Seismik-API-Key: sk_live_..." https://api.seismik.org/v1/events/history

Las cuotas gratuitas son limitadas y no incluyen datos personales. Ningún comando IoT opera equipos reales sin una integración local autorizada y redundante.

# Código de conducta

Seismik busca una comunidad segura, inclusiva y técnicamente rigurosa. Trata a
todas las personas con respeto, acepta correcciones de buena fe y evita acoso,
discriminación, amenazas, publicación de información privada o uso del proyecto
para generar alarma deliberadamente.

Los mantenedores pueden editar o retirar contenido y limitar la participación
ante conductas dañinas. Reporta incidentes de forma privada mediante el canal
indicado en `SECURITY.md`; no publiques información personal en un issue.

Este código aplica a repositorios, revisiones, chats, eventos y representaciones
públicas del proyecto. Su aplicación debe ser proporcional, documentada y con
posibilidad de apelación ante mantenedores no involucrados.
